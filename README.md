# SecureVoteAI - AI-Based Secure Voting DApp

This repository contains the full source code for the B.Tech Final Year Project: **AI-Based Secure Voting DApp Using Blockchain, Smart Contracts, AI Fraud Detection, and Face Verification**.

## Directory Structure

- `backend/`: Node.js & Express.js REST API with MongoDB Atlas integration.
- `frontend/`: React.js (Vite) + Tailwind CSS + TypeScript frontend interface.
- `blockchain/`: Solidity Smart Contracts & Hardhat development environment.
- `ai/`: Python & FastAPI service for anomaly detection and fraud analysis.
- `face-verification/`: Biometrics and liveness detection models.
